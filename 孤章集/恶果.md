# 恶果

# 水底

实验室的通风管道在头顶嗡鸣，像某种濒死动物的喘息；灌满淡黄色液体的巨罐伫立在走廊两侧，其中的生物缓缓转圈，不时冒出点点气泡

“荒谬，真是荒谬……”一个长相硬朗的中年男人喃喃自语地快步走过走廊，停在一个巨罐前，透过淡黄色的液体看到里面浮着一个蜷缩着的少女

男人从白色的研究服口袋熟练地掏出一张印着自己头像的卡片刷过巨罐下方的装置，“乌尔托斯·梅林，允许访问。”无感情的细微电子音响起，被称为乌尔托斯·梅林的男人双手手指飞快地在装置显示屏上敲击。随着最后的用力一按，他面前巨罐里的淡黄色液体缓缓下降，消失，盖子弹开，玻璃降下，只留下其中湿漉漉的长发少女静静地躺在底座上

梅林急忙掏出口袋里提前塞好的毛巾抱在少女身上顺势抱起，感受到梅林胸口温度的少女缓缓睁开双眼。那是不同于某人的酒红色。

“我们要走了。”梅林抱着少女走进走廊尽头的办公室，将少女轻轻地从怀里抱到地上，从置物架上拉下一件成人尺寸的灰色外套裹在她身上，抓住这个比他矮一个头的少女那白皙的手臂“跟着我，别走丢。”

少女只是用酒红色的眼睛看着眼前这个为她忙碌的男人，安静地遵循他的话语

“莫比乌斯。”男人整平了少女衣服上最后的褶皱说道，“从现在起你的名字不再是一串数字了，不再是那个恶心的S50015+99，你现在的名字是‘莫比乌斯’，知道了吗？”少女轻轻点了点头，嘴角泛起一丝不易察觉的抽动

“趁现在跟我走。”

# 水面

男人带着少女穿过一片寂静的楼层，随处可见的刺眼白色或深邃的黑色让人心生压抑，特别是摘下那颗实验“恶果”的梅林

楼层尽头是一扇厚重的银色电梯门，梅林掏出与之前不同的身份卡刷过电梯的控制面板，身份卡上分明写着“瑟希·罗杰”。轻微的碰撞声从上方传来，梅林不禁更加紧绷，紧紧握着少女的手臂

“疼…”沉默许久的少女缓缓开口吐出一个字，梅林赶紧减小了力度：“抱歉…我太紧张了…”他的心脏猛猛跳动着，这躺电梯是他唯一的希望

随着清脆的叮声，厚重的电梯门缓缓开启，梅林拉着少女快步走进布满惨白光线的电梯，颤抖地快速按动关门键，直到那银色的门口完全关闭，感受到一股下压的力才罢休

30秒，他们上升了整整30秒

随着下压的感觉逐渐消失，电梯门慢慢地移向两侧，一股冰冷的气流瞬间冲进

梅林缩了缩身子，抓着少女的手臂走出电梯

电梯所在的地面是藏在园区东侧的一座废弃水泵房里，男人蹲下身费力地抬起略微生锈的卷帘门——这对于从事研究的人来说真的很难。他从水泵房的杂物架里翻出一袋衣服，脱下白得刺眼的研究服，换上那灰色的衬衫，不时回头看少女是否还在，而少女也很配合地站在原地，静静地用酒红色的双眼看着这个带她上来的男人

# 何去何从

“走吧，逃出这个地方。”梅林整了整衣领，抓着莫比乌斯的手就往卷帘门外走去

此时已经是深夜了，但还是下着雨。灰暗的天空下，一个男人带着一个少女横穿废弃的园区

走出园区的铁栏门，一道刺眼的白光照在他们脸上，随即是强烈摩擦地面的声音。一辆白色的房车精准停在他们面前，从驾驶座的窗户里探出有着一头米黄色长发的少女那干净的脸

“上车，赶在天亮前到地方。”驾驶房车的少女简洁地抛下一句话就缩回了车里，梅林赶忙拉着莫比乌斯登上房车后面遥控开启的折叠门。门哐当一声关上，将冰冷空气搁在了外面，发动机开始嗡嗡作响。梅林一眼看到了驾驶座后面挂着的日历：2067年10月15日

梅林拉着莫比乌斯坐在绿色的沙发上，长舒了一口气，伸出手轻抚莫比乌斯乌黑的长发自言自语着“要是能够顺利到达…”

“唉你少说两句，别等会乌鸦嘴把事情搞麻烦了。来之前买的衣服，你给她试试合不合身。”在前面驾驶房车的少女腾出一只手从副驾座位上甩出一堆衣服，其中不乏内衣内裤，甚至还有裙子，非常精准扔到了沙发上。莫比乌斯看着那堆五颜六色的布料，酒红色的眼睛里没有困惑，也没有好奇——只有一种空荡荡的平静

“米娜，真的很感谢你…”梅林翻着那堆布料轻声感谢，被称为米娜的少女向后摆了摆手说：“我说你啊，什么时候性格能和外貌匹配一下，你还是我老师的时候我就觉得别扭了，看起来像个黑帮老大，怎么说话跟弱书生一样，读书腐蚀心灵呀\~\~”米娜说完后自顾自地咯咯笑着

梅林自顾自地脱下莫比乌斯身上有些湿的灰色外套，雪白的肌肤暴露在空气中。梅林把外套放在一边，从一堆衣服里挑出了一件白色长袖T恤和一条黑色的直筒裤“我看看…手抬一下，尺寸好像刚刚好。”梅林的话语和窸窸窣窣的衣物摩擦声引得米娜从驾驶座转过头看向他们，她眯着眼睛一瞅，惊的要跳起来：“你在干嘛呀，怎么内衣都没穿，我看她也有二十来岁的样子了，唉真的是，我来。”米娜拉动方向盘右边的蓝白色拉杆，随着一声从驾驶台传来的“Turn up”，方向盘中间的卡牌装饰自动翻到背面，印着一个类似Z的红色图案“自动驾驶了，你坐边上去。”梅林只好怏怏地坐到收纳桌边上的折叠椅上

穿衣服的过程很安静，莫比乌斯配合地抬起胳膊、伸进袖子，像一个人偶。米娜帮她扣内衣背扣的时候，手指碰到她的脊柱，能感觉到每一节棘突微微凸起——太瘦了

“好了。”米娜从沙发上站起来，退后一步，打量了一下。T恤有点大，内衣和直筒裤倒是刚刚好，这时她注意到了莫比乌斯空荡荡的双脚：“啊，忘记买鞋子了，先用我这的拖鞋凑合一下，到地方再去店里买。”说着她从固定在车壁上的柜子里提出一双青色的拖鞋放在莫比乌斯脚边

莫比乌斯低头看着自己的新衣服，又抬头看向米娜。嘴唇动了动，但没有发出声音

米娜伸了个懒腰，转身打开身后的冰箱里拿出一瓶水和一块压缩饼干，递过去，“你大概很久没吃过东西了吧。”

莫比乌斯接过水瓶，有些费力地拧开盖子，喝了一小口。水顺着喉咙滑下去，胃里传来一阵陌生的感觉。她又咬了一口压缩饼干，嚼了很久才咽下去。

“谢谢。”声音很小，像是从很远的地方传来的，不知道梅林和米娜有没有听见

“唉，还是手操有感觉啊，自动驾驶终究差点意思。”米娜不知何时已经回到了驾驶座上拉动拉杆。随着一声“Turn up”，方向盘中间的卡牌再次翻面，露出印有黑桃图案的一面

“我们…要去哪…”莫比乌斯有些不安地用酒红色的眼睛瞟了一眼靠在折叠椅上的梅林。梅林摸了摸下巴没剃干净的胡茬，犹豫了一会，但还是说了：“伦敦，我们要到伦敦去，那里的治安力度也许能暂时打消那群疯子追杀的想法。”莫比乌斯没有再问什么，只是低着头默默摆弄着手指。梅林看向窗外的一片夜色。他在想，自己做对了吗。
