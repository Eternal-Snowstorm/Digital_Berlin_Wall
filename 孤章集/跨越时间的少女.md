# 跨越时间的少女

# 梦

黑暗如汹涌的潮水，瞬间吞噬了蜷缩的少女，她感到窒息，眩晕。震动和巨响不断，少女想逃，但身体不听使唤，只能无力跌入黑暗的漩涡

少女任由自己坠入梦乡，经过一个又一个世界，与无数的人相见、分离。在万千个世界的旅途，少女忘记了过往，模糊了梦与现实的边界。唯有那个身影…

# 第一次接触

最先感知到的是光

不是休眠仓里那种持续了不知多少年幽暗的，仿佛凝固的蓝光。是另一种光——刺眼的，摇晃的，带着温度的白光，像刀子一样从眼皮的缝隙里捅进来。

少女想躲开，但难以动弹

像是被抽空了骨头，只剩下软塌塌的皮肉。她试图睁开眼睛，眼睑却沉重得像生了锈。只有睫毛微微颤动，扫过某种冰凉的东西——是仓门吗？还是……有人正俯身看着

“还活着！”一个声音穿透了嗡嗡的耳鸣，是她熟悉的法语

少女的喉咙动了动，想说话，却只发出一声微弱的、沙哑的气音。她忽然想起一件事——

上一次她拼命拍打仓门的时候，也是这样发不出声音的

# 新世界

卜开始回忆，但记忆就像坠到地面的玻璃，错落，锋利

姐姐的脸，隔着仓门，泪水划过脸颊，天花板在崩裂。世界就像，变成了碎片

然后是一片空白，四十九年零两个月的空白

“——能听到我说话吗？喂？”

一只手握住了她的手腕，温热的，有脉搏。一下，两下，三下，活人的脉搏。

卜终于睁开了眼睛

光线像洪水一样涌进来，她看见了破裂的混凝土天花板，看见了纵横交错的钢筋，看见了灰蒙蒙的天空，然后看见了一张俯视着她的脸

米黄色的麻花辫，暗金色和碧绿色的眼睛，一个黑白相间的护目镜卡在额头上

“你是……”卜的嘴唇动了动，吐出两个干涩的字眼

“嘛，你叫我贞德就好了。”女人笑了，很好看

贞德

圣女贞德，被烧死的那个

“你……”她艰难地转动脖子，看向四周。这是一片废墟，到处都是扭曲的金属和碎裂的混凝土块

“这里是开协的前身遗址，”贞德说，“我本来是想来找莱尔博士留下的遗产的，结果发现了你。你躺在一个休眠仓里，仓门上有法语的警告标识——‘谢诺私人实验，请勿触碰’。谢诺？你认识莱尔·谢诺吗？”

莱尔

这个名字像一块倒转的表盘，碎裂的记忆不断重组

眼眶发热，泪水毫无预兆地涌了出来，任凭泪水顺着脸颊滑落

贞德有些慌乱地松开手，从风衣口袋里掏出一块手帕，把手帕轻轻盖在她的眼睛上“这应该不是休眠症的影响吧…你能动吗？”

卜缓缓移动手臂，试图撑起身体，但手臂一软，又倒了回去

贞德二话不说，直接把手臂伸到她的后背和膝盖下方，用力把她抱了起来

突如其来的冲击让卜有点头晕目眩

“好轻…”贞德皱了皱眉

她就这样被一个陌生的女人抱着，穿过废墟

微风吹过，带着一股陌生的气息。这就是，四十九年后的世界

# 表侧-过去

贞德把抱到了不远处自己作为移动基地的改装房车里，暂时安顿这位跨越时间的少女

房车里面堆满了各种东西：相机、镜头、笔记本电脑、充电线、几本漫画书、一盒吃了一半的曲奇饼干、还有一盆快要枯死的绿萝。唯一整洁的地方是一个折叠桌，上面放着一台看起来相当专业的电台终端

“有点乱，”贞德有些不好意思地把沙发上的衣服抱起来扔到一边，“你先坐，我给你倒水，得把你带到柏林节点…”

卜靠在沙发靠垫上，环顾四周。阳光从车窗照进来，在空气中画出几道光柱。灰尘在光柱里缓缓飘浮，灰蒙蒙的天空漏下几束阳光，说不上来是压抑还是如释重负

一切都让人感到陌生

四十九年前的世界不是这样的。那时候到处都是警报声、广播声、匆忙的脚步声、压抑的哭泣声。那时候天空是灰色的，空气是焦糊的，每一次呼吸都像是在吞咽灰烬

“给。”贞德递过来一杯温水，“你睡了多久？休眠仓的信息我调不出来，有些年头了，我对这方面没什么了解。”

卜接过水杯，低头看着杯中微微晃动的水面

“四十九年吗…”她轻轻说出了这个数字

贞德正要坐下，听到这句话，整个人僵住了

“……什么？”

“我是在2026年被关进去的，车上的日历标注的是2076年…”卜抿了一口水，温热的液体滑过喉咙，带来一种久违的实感

她慢慢坐到卜对面，摘下额头上的护目镜，放在桌上，伸手翻过卜挂在脖子上的吊牌，上面的文字模糊不清，但有一个不同，贞德的的确确看到了那个词

谢诺

“谢诺…”贞德的声音有些沙哑，“你和那个莱尔·谢诺是什么关系？”

卜握紧了水杯，水面在不断颤抖

“她是我姐姐…”

沉默

就像是，时间被按下了暂停

贞德转过身从旁边的抽屉里翻出了一沓照片摆在少女的面前

废墟，扭曲的金属，破碎的混凝土

“这是开协前身遗址。”她指着其中一张照片，“我是在这里找到你的。这里在2026年11月遭受了导弹袭击，整个地下设施几乎完全坍塌。我本来是想来找……找莱尔博士可能留下的资料。但我只找到了你。”

卜看着那张照片，表盘的指针开始倒转

2026年11月21日

那天的事像碎片一样涌回来——莱尔递给她的一杯水，说“喝了好好睡一觉”；她喝完水后忽然袭来的困倦；醒来时发现自己被关在休眠仓里；莱尔隔着仓门设定程序的身影；她拼命拍打仓门，莱尔却始终没有回头；天花板开始崩裂；莱尔终于转过身来，眼角滑落一滴泪水——

然后就是空白

四十九年的空白

“她……”卜的声音颤抖起来，“她……还活着吗？”

贞德沉默了几秒钟，然后摇了摇头

“我不知道。”她说，“但根据记录，那次袭击几乎没有幸存者。整个地下设施都被掩埋了。我找到你的时候，你的休眠仓在一个相对完整的角落里，被一些钢结构保护住了。但其他地方……”

她没有说下去

# 里侧-现在

卜低下头，看着水杯里自己的倒影

淡蓝色的长发散落在肩头，金色的眼睛含着泪水

四十九年过去了

她一点都没变

而莱尔——

“你叫什么名字？我看吊牌上只有姓氏。”贞德忽然问

卜愣了一下

“名字…我的名字…”

是啊，这位少女，穿过时间的缝隙，走过万千世界的少女

她的名字是什么

不愿回想，过去令她恐慌

少女抛弃了谢诺这个姓氏，她选择了那个曾行于世间的名字——

“卜。”她说，“叫我卜就好。”

贞德歪了歪头：“卜？就一个字？”

“嗯。”

“那你的真名呢？”

卜沉默了一会

“我不知道，卜就是我如今的真名。”她说

贞德看了她一会儿，没有再追问

“好，”她点点头，“那么接下来，你有什么打算？”

# II-未来

卜看向窗外的天空

乌云不知何时散去，露出湛蓝的天空，比过去蓝的多

“不知道。”她说

贞德沉默了几秒钟，然后忽然站起来，走到房车门口，拉开门

“嘛，那就先住下来，”她回头看着卜，“之后把你带到柏林节点好了。这辆车虽然乱，但多一个人还是挤得下的。”

阳光从门外涌进来，照在贞德米黄色的麻花辫上，照在她暗金色和碧绿色的眼睛里，照在她微微扬起的嘴角上

卜看着那道阳光，忽然想起了莱尔眼角滑落的那滴泪水

她眨了眨眼睛，泪水又落了下来

“好。”她说
