## 参与撰写

1. 先读 [设定集模板/0-模板总说明.md](设定集模板/0-模板总说明.md) 了解命名、标题层级与跨文件引用约定；
2. 复制对应模板（[人物](设定集模板/1-人物设定集模板.md)／[势力](设定集模板/2-势力设定集模板.md)／[世界观](设定集模板/3-世界观设定集模板.md)／[孤章](设定集模板/4-孤章模板.md)／[武器与装备](设定集模板/5-武器与装备设定集模板.md)（分型骨架：[枪械](设定集模板/5a-枪械模板.md)／[近战武器](设定集模板/5b-近战武器模板.md)／[爆炸物](设定集模板/5c-爆炸物模板.md)／[平台与装具](设定集模板/5d-平台与装具模板.md)）／[文档库](设定集模板/6-文档库模板.md)）撰写；
3. 修改或联动他人设定前，请先阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 设定集撰写规范第五条（需原作者或管理员同意）；
4. **新增文件后不需要在别处登记**。只要填好自己文件里的登记字段（人物的 `**所属势力**`、篇目的 `**关联人物**`、装备的 `**所属势力**`），反向索引会自动生成；唯一需要追加的是两个全局协作点——[历史年表](世界观大纲/历史年表.md) 与 [术语与概念](世界观大纲/术语与概念.md) 末尾的 `## 追加区`；
5. 提交前可运行 `node 工具/派生视图.js` 刷新 [派生视图/索引.md](派生视图/索引.md) 并校验登记字段。

尚未填写的章节请统一写 `（待补充）`，不要删除章节标题，以便他人按结构补写。
