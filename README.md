## 参与撰写

1. 先读 [设定集模板/0-模板总说明.md](设定集模板/0-模板总说明.md) 了解命名与标题层级约定；
2. 复制对应模板（[人物](设定集模板/1-人物设定集模板.md)／[势力](设定集模板/2-势力设定集模板.md)／[世界观](设定集模板/3-世界观设定集模板.md)／[孤章](设定集模板/4-孤章模板.md)／[武器与装备](设定集模板/5-武器与装备设定集模板.md)）撰写；
3. 修改或联动他人设定前，请先阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 第五条（需原作者或管理员同意）；
4. 新增文件后，在 [索引.md](索引.md) 登记。

尚未填写的章节请统一写 `（待补充）`，不要删除章节标题，以便他人按结构补写。待补清单见 [索引.md](索引.md) 第七节。
