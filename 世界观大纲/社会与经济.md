### 货币与金融

**一般等价物:token**

- **名称** token 不设中文名,各方文书与口语一律使用 token.企业公文的正式表述为"算力结算单位";教会称"赎价", 算力游牧民称"干 token".
- **由来** 2039 年算力霸权定型时,信通复合体推行链上结算,协议中表示"结算凭证"的字段名为 `token`;此后合约, 终端与调度代码沿用该字段, 遂以 token 称呼这一货币.
- **计量锚** 1 token 相当于将 1 克标准物质完成"数据化-传输-再物质化"全流程的平均算力消耗;相关技术的不合理性不作深究(见 `CONTRIBUTING.md` 设定集撰写规范第四条).
- **实物形态** 券链(市面口语"链"):一条写入一次性算力授权码的薄膜带,格间压有预制刻痕,可徒手撕开,撕到哪一格就是哪一格的钱.
- **面额** 一条券链 100 格,分三种型号,以刻痕间距与膜色区分:零链(每格 0.1 token,一条 10),链(每格 1 token,一条 100),千链(每格 10 token,一条 1,000).从链上撕下的小段仍按旧称叫"碎片",用于 0.1-10 token 的支付.**格不可再分**,0.1 token 是最小支付单位,市面标价因此普遍向 0.1 对齐(赎罪券 0.5 token 即 5 格);一条千链约合边缘劳动者一百天以上的收入,底层几乎无人经手整条.
- **离线校验** 券链不依赖网络即可验证,因此在断电的企业辖区,长期保持静默的巴黎节点,算力游牧民活动的荒野中同样有效.校验只用一只"读数夹":夹住待付的格,读出授权码,同时读该格膜面在镀膜时随机生成的纹理.**夹子没有数据接口,只认夹在嘴里的实物**--抄下的号码与拓印的纹理都无效,能造出纹理自洽的膜的只有信通复合体的镀膜产线.
- **花费即销毁** 付款时读数夹对待付的格施加一次脉冲,熔断其写入层(口语"烧格").烧过的格物理失效,不可复原,余额按未烧格计.一段链在物理上只能被花掉一次.沿刻痕撕开是合法分割,两段各自完整;**越痕剪断**会使断口两侧的格作废,故"剪链"是外行做法,也是收赃者判断货物来路的方法.货币犯罪的形态于是只剩抢与骗,没有伪钞.

**流通方式**

- **企业辖区(法偿地位)** 工资,消费,罚金与医疗账单一律以 token 结算.医药复合体的"先治疗后付款"实为发放一笔 token 计价的债权,债务农奴持有的永远是负数 token.信通复合体对每笔链上结算抽取抽成, 即其铸币税.
- **开源协议联盟(对外窗口制)** 节点内部不使用 token,由"莱茵河""BAS""康乃馨"按劳动与需求直接配给(见 `开源协议联盟.md`).token 仅用于节点对外的采购,雇佣与情报支付;联盟内部跨节点结算使用基于"红旗"加密的记账凭证,与 token 并行.
- **教会(主要承兑方)** 赎罪券以 token 标价;教会凭遍布各势力的信徒网络,成为少数能被所有阵营接受的承兑方,并以此换取物资与保护,构成其财政的一部分(见 `教会.md`).
- **算力游牧民** 不承认任何账本,只接受可离线验证的券链,以拾得的落件换取(见 `爱丽丝.md`).
- **底层秩序** 记忆水晶球,记忆毒品与义体零件以碎片标价;数据清道夫是 token 现金经济最活跃的参与者.
- **长老会** 杀手是唯一能跨境执行契约的群体,"token 的兑付不得拒收"被列入杀手共识,拒收者失去全行业的信用(见 `长老会.md`).
- **链上经济的门槛** 账本经济(工资,债务,罚金,赎罪券)须以神经接口或植入体完成身份绑定,未接受义体化改造者被排除在外, 只能以物易物;券链的离线校验用一只廉价读数夹即可完成, 其流通不以改造为前提.

**交易与回兑**

- **当烧(陌生人之间)** 买方递链,卖方用读数夹夹住待付的格数;夹子报"纹理对,码对,未烧",随即烧格,卖方收下带烧痕的链(余格继续流通),买方取回余链.全程离线,数秒完成;烧痕双方共见,事后无从抵赖.
- **挂账(熟人之间)** 摊主记人情账,旬末结一次.券链不可挂失, 不生息, 不能透支;欠与还是同一件东西.
- **承兑(跨阵营与大额)** 数额大到当场点不清,或交易双方互不认账时,改走承兑:教会收链开票,凭遍布各势力的信徒网络把链换成任何阵营都认的东西(见 `教会.md`);长老会以行业信用担保"token 的兑付不得拒收"(见 `长老会.md`).
- **回兑与铸币税** 券链是算力预付凭证:清算所收链,读未烧格,记入链上账户,链当场打孔作废,作废箔回收.信通复合体的铸币税有两个来源: 链上结算的抽成, 以及**永不回兑的沉没链**(遗失, 烧毁, 随尸体埋掉或烂在荒野里的链, 其算力额度从未被提取, 直接成为净得);治安与清运因此涉及复合体的收入(见 `数据清道夫.md`).
- **大额不走实物** 一条券链的上限是 1,000 token:寻血犬无人机(4,000-8,000),单兵外骨骼(30,000-60,000)与杀手合约(2,000-10,000)这类支付只走账本,承兑票据或担保.原因在风险: 券链不可挂失, 不可追索, 被盗即灭失;大额持有者把钱留在账上.
- **墙外折价** 只有复合体的清算所能把链换成算力额度,故**辖区之内链是法偿,辖区之外链是商品**.离清算所越远, 带得回去的概率越低, 链越折价.当开协用自己的数据化网络回兑时, 两套链之间出现汇差.
- **无改造者的代价** 不能开户就不能自己回兑,只能经柜台,教会或帮派**代兑**并付抽水:无改造者能持有链,却不能存链.(见 `肉体原教旨主义兄弟会.md`).

**物价基准**

以下数值为全设定集共用的基准价,供各势力,人物与装备设定引用时对齐;调整须在本节登记.计价前提:1 token 相当于将 1 克标准物质完成"数据化-传输-再物质化"的算力消耗,标准搬运距离取 500 公里(欧洲各节点之间的典型干线距离).本地生产, 不经搬运的商品只计其生产算力成本, 远低于跨墙商品.

**基准锚点**

| 项目 | 价格 |
| --- | --- |
| 最低档营养膏(约 800 大卡) | 1 token |
| 1 公斤物质,经数据化搬运 500 公里 | 1,000 token |
| 同城短途搬运(10 公里内) | 约 20 token/公斤 |

即:**1 token 大致就是底层社区一顿最寒酸的饭**;而把 1 公斤东西搬过 500 公里的墙,需要边缘劳动者不吃不喝一百天以上.

**生存开销(企业辖区,按月计)**

两栏的分界是是否持有可结算身份:有身份者能开户,结算与就医,无身份者被排除在账本之外,只能以物易物(见本节"链上经济的门槛").

| 项目 | 有身份可结算 | 失去选择权者 |
| --- | --- | --- |
| 基础营养(2000 大卡/日) | 约 75 token/月 | 25-40 token/月(拾荒,互助与配给残渣) |
| 净水 | 约 10 token/月 | 5-10 token/月(公共取水点,过滤器自修) |
| 栖身 | 胶囊床位合租约 60 token/月 | 0-10 token/月(废弃建筑,通铺) |
| 最低档数据接入(链上身份与结算的前提) | 20 token/月 | 0(不接入,不能开户与回兑) |
| 义体基础维护(已改造者必需,欠费即停机) | 30 token/月 | 0(黑市零件按件凑,无定期维护) |
| 合计 | 约 195 token/月 | 25-60 token/月 |

体系外一栏的低价换来的结果是不被计入,无医疗,义体停机即等死.同一条街上两栏人的月度开销相差四到八倍,差别在账本状态,与其手上那一刻有多少钱无关.

**收入水平**

各阶层占企业辖区常住人口的比例列在表内,供势力与人物设定对照取用.

| 阶层 | 占辖区常住人口 | 日收入 | 月收入 |
| --- | --- | --- | --- |
| 失去选择权者 | 37% | 无现金收入 | 无现金收入 |
| 边缘劳动者(底层社区,清道夫帮派外围) | 25% | 5-10 token | 150-300 token |
| 辖区登记劳工(可链上结算) | 20% | 20-40 token | 600-1,200 token |
| 技术员与基层管理 | 12% | 80-250 token | 2,400-7,500 token |
| 中层管理与专业人员 | 4% | 300-800 token | 9,000-24,000 token |
| 高层管理 | 1.5% | 折算日支配额 2,500-8,000 token | 以算力额度与股权计 |
| 资本所有者及代理人 | 0.5% | 折算日支配额 20,000 token 以上 | 以算力额度与股权计 |

失去选择权者由五部分构成:医疗与住房债奴 15%,成瘾依赖者 6%,无身份流民与落件拾荒者 9%,义体停机者与被除名者 4%,被收押与被资产化者 3%.这一层没有现金收入,生计来自拾荒,互助,被代管或被资产化.

高层管理与资本所有者的收入按剩余价值分配计,不按工日计价,表中记的是折算日支配额;中层管理的收入是监督劳动的价格加部分剩余分成,故其人可被下压回技术员层,也可被上提为代理人.

差距的量级:边缘劳动者与技术员相差一个数量级,与高层管理相差 250-1,600 倍,与资本所有者相差 2,000 倍以上;按月收入计,两端相距约 4,000 倍.

**医疗价目(债务农奴陷阱的算术)**

同一台手术在四条渠道上有四个价,差别在付款人的账本状态.

| 项目 | 挂牌价(辖区登记劳工以上) | 债务价(边缘劳动者) | 黑市价(黑医与清道夫体系) | 慈惠价(教会诊所) |
| --- | --- | --- | --- | --- |
| 常规门诊 | 40-80 token | 名义同挂牌价,实付记负数 | 5-15 token | 0-5 token(凭赎罪券) |
| 义体大修 | 1,500-4,000 token | 名义同挂牌价,记账 | 200-600 token | 0-5 token(只保不死) |
| 急诊抢救(生命树私立医院等) | 6,000-12,000 token | 名义同挂牌价,记账 | 300-900 token | 0-5 token(排队,只保不死) |
| 廉价植入体(新伊甸跨界款) | 300-900 token | 记账 | 按件议 | 不提供 |
| 官员级改良型植入体(黑市流出) | 50,000-200,000 token | 不适用 | 按件议 | 不提供 |
| 医疗债务计息 | 周息 0.5%,复利(年化约 30%) | 同左 | 不适用 | 不适用 |

四条渠道的钱各有来处.挂牌价的现金来自登记劳工以上阶层,约占医疗现金收入的六成.边缘劳动者的账单当场按 15-25% 的贴现率卖断给追债方与资产市场,医院拿走现金,债务人的对手方换成追债方.失去选择权者的账面债权几乎全额坏账,债权人处置的是人本身--劳动年限,义体回收与器官,回收方是数据清道夫与长老会的外围.医药复合体因此对濒死负债者必定施救:救活一次即造出一笔可出售的资产.

一次急诊抢救约合边缘劳动者两到六年的全部收入;6,000 token 的债务每年产生约 1,800 token 的利息,高于该阶层一年可偿还的金额, **本金永不减少**.

**量级参照**

- 一具 80 公斤的人体经数据化搬运 500 公里需 80,000 token, 约合边缘劳动者二十年以上收入;底层越墙只能走火车, 房车与走私路线(见 `恶果.md`,`灰色天使_降临_.md`).
- 开协节点对外的设备采购,按登记劳工月薪量级折算:一台豺狼级外骨骼约合一名工程师半年到两年的产出,故联盟大量依赖缴获与自研(见 `开源协议联盟.md` 各节点的物资紧张记述).
- 赎罪券单价 0.5-3 token, 为最底层信徒可负担;教会财政的现金部分只依赖销量而非单价, 田庄产出折不成钱, 不补这个缺口(见 `教会.md`).
- 各节点的自动化调配系统("莱茵河""BAS""康乃馨")所消耗的算力由节点自身产出承担, 不进入 token 市场.

**换算参照(面向读者与创作者,非世界观内设定)**

世界观内不存在现实货币,以下仅用于建立量级感.

**主锚:1 token ≈ 2.75 欧元 ≈ 3 美元 ≈ 21 元人民币**

该锚取自本世界观舞台(欧洲)的底层食品篮子:一名底层居民维持 2000 大卡/日需 2.5 token 上下,对应现实中欧洲最低限度的食物开销.

**不列整表,只给漂移区间**: 以底层生存为锚约 2.5-3 欧元;以企业中层或高管收入为锚约 0.5-1 欧元;以医疗服务为锚约 1.5-2 欧元.同一枚 token 在不同的商品篮子上换出不同的现实货币数,排成一张整表会把这些漂移抹平成确定值.需要具体量级时按主锚乘除,允许一个数量级的误差.

**2075 年之后的动摇**

2075 年 12 月 26 日东亚大国开源物质数据化技术后,开源协议联盟据其资料着手建立基于"红旗"加密的应用物流网络.联合电讯股票在 12 月 27 日至次年 2 月 3 日累计蒸发 1.1 亿 token.搬运物质的算力不再由信通复合体独占; token 的锚定权仍握在它手里, 但它不再是唯一通行的计价体系:联盟的物流网络与跨节点记账不以 token 结算, 企业账本首次可以被绕开.至主线时间点(约 2077 年), **谁有权定义 1 token 值多少克物质**是双方冲突的核心议题之一: 企业坚持该定义权只能属于自己, 联盟则否认任何私人主体有权为物质定价.
