### 货币与金融

**一般等价物：token**

- **名称** token 不设中文名，各方文书与口语一律使用 token。企业公文中的正式表述为「算力结算单位」，但除合同与法规外极少使用；教会称其为「赎价」，算力游牧民则称「干 token」。
- **由来** 2039 年算力霸权定型时，信通复合体推行链上结算，协议中表示「结算凭证」的字段名为 `token`。此后每一份合约、每一台终端与每一行调度代码都沿用该字段，三代人之后，整个世界便以 token 称呼这一货币。
- **计量锚** 1 token 相当于将 1 克标准物质完成「数据化—传输—再物质化」全流程的平均算力消耗。在本设定集的技术条件下，能够跨越数字柏林墙搬运物质的东西只有算力，token 因而同时是能源、运费与生产力的度量；相关技术的不合理性不作深究（见 `CONTRIBUTING.md` 02 第四条）。
- **实物形态** token 晶：封存离线可校验算力授权码的水晶状介质，与数据清道夫经营的「记忆水晶球」同源不同用。常见面额为 100 token 与 1000 token；可徒手掰开的小额介质称「碎片」，用于 0.1—10 token 的支付，断面离体即失效，底层社区因此难以伪造零钱。
- **离线校验** token 晶不依赖网络即可验证，因此在断电的企业辖区、长期保持静默的巴黎节点、算力游牧民活动的荒野中同样有效。这是它得以成为跨阵营一般等价物的直接原因。

**流通方式**

- **企业辖区（法偿地位）** 工资、消费、罚金与医疗账单一律以 token 结算。医药复合体的「先治疗后付款」实为发放一笔 token 计价的债权，债务农奴持有的永远是负数 token，与「债务与医疗」一节互为表里。信通复合体对每笔链上结算抽取抽成，即其铸币税，也是「算力霸权」在日常层面的形态。
- **开源协议联盟（对外窗口制）** 节点内部不使用 token，由「莱茵河」「BAS」「康乃馨」按劳动与需求直接配给（见 `势力设定集/开源协议联盟.md`）。token 仅用于节点对外的采购、雇佣与情报支付；联盟内部跨节点结算使用基于「红旗」加密的记账凭证，与 token 并行。
- **教会（主要承兑方）** 赎罪券以 token 标价；教会凭遍布各势力的信徒网络，成为少数能被所有阵营接受的承兑方，并以此换取物资与保护，构成其财政的一部分（见 `势力设定集/教会.md`）。
- **算力游牧民** 不承认任何账本，只接受可离线验证的 token 晶，以捕获的卫星数据流换取（见 `人物设定集/算力游牧民/爱丽丝.md`）。
- **底层秩序** 记忆水晶球、记忆毒品与义体零件以碎片标价；收尸人黑帮与数据清道夫是 token 现金经济最活跃的参与者。
- **长老会** 杀手是唯一能跨境执行契约的群体，「token 的兑付不得拒收」被列入杀手共识，拒收者失去全行业的信用（见 `势力设定集/长老会.md`）。
- **链上经济的门槛** 账本经济（工资、债务、罚金、赎罪券）须以神经接口或植入体完成身份绑定，未接受义体化改造者被排除在外，只能退回以物易物——`势力设定集/肉体原教旨主义兄弟会.md` 的立场由此获得了经济后果。token 晶本身的离线校验可用廉价读取器完成，故其流通并不以改造为前提。

**物价基准**

以下数值为全设定集共用的基准价，供各势力、人物与装备设定引用时对齐；调整须在本节登记。计价前提：1 token 相当于将 1 克标准物质完成「数据化—传输—再物质化」的算力消耗，标准搬运距离取 500 公里（欧洲各节点之间的典型干线距离）。**本地生产、不经搬运的商品只计其生产算力成本，故远低于跨墙商品**——这正是数字柏林墙在经济层面的直接体现。

**基准锚点**

| 项目 | 价格 |
| --- | --- |
| 最低档营养膏（约 800 大卡） | 1 token |
| 1 公斤物质，经数据化搬运 500 公里 | 1,000 token |
| 同城短途搬运（10 公里内） | 约 20 token／公斤 |

即：**1 token 大致就是底层社区一顿最寒酸的饭**；而把 1 公斤东西搬过 500 公里的墙，需要底层劳工不吃不喝一百天。

**医疗价目（债务农奴陷阱的算术）**

| 项目 | 价格 |
| --- | --- |
| 常规门诊 | 40—80 token |
| 廉价植入体（新伊甸跨界款） | 300—900 token |
| 义体大修 | 1,500—4,000 token |
| 急诊抢救（生命树私立医院等） | 6,000—12,000 token |
| 官员级改良型植入体（黑市流出） | 50,000—200,000 token |
| 医疗债务计息 | 周息 0.5%，复利（年化约 30%） |

一次急诊抢救约合底层劳工 2—4 年的全部结余，而 6,000 token 的债务每年产生约 1,800 token 的利息，高于该阶层一年能够偿还的金额——**本金永不减少**。加之医药复合体对濒死负债者必定施救，每一次「被救活」都追加一笔新债务，债务农奴因此被终生锁死（与「债务与医疗」一节互为表里）。

**量级参照**

- 一具 80 公斤的人体若全程经数据化搬运 500 公里，需 80,000 token，约合底层劳工二十年收入；因此**墙对穷人是物理的，对富人是数据的**——底层越墙只能走火车、房车与走私路线（见 `孤章集/恶果.md`、`孤章集/灰色天使_降临_.md`）。
- 开协节点对外的设备采购，按登记劳工月薪量级折算：一台豺狼级外骨骼约合一名工程师四年的产出，故联盟大量依赖缴获与自研（见 `势力设定集/开源协议联盟.md` 各节点的物资紧张记述）。
- 教会把赎罪券单价压在 0.5—3 token，是为了让最底层的信徒也买得起，其财政因此依赖销量而非单价（见 `势力设定集/教会.md` 的财政困局）。
- 各节点的自动化调配系统（「莱茵河」「BAS」「康乃馨」）所消耗的算力由节点自身产出承担，不进入 token 市场——联盟因此得以在不使用 token 的前提下维持内部运转。

**换算参照（面向读者与创作者，非世界观内设定）**

世界观内不存在现实货币，以下仅用于建立量级感。折算按 1 欧元 ≈ 7.6 元人民币、1 欧元 ≈ 1.08 美元。

**主锚：1 token ≈ 2.5—3 欧元 ≈ 2.7—3.2 美元 ≈ 20—24 元人民币**

该锚取自本世界观舞台（欧洲）的底层食品篮子：一名底层居民维持 2000 大卡／日需 2.5 token 上下，对应现实中欧洲最低限度的食物开销。为便于速查，下表按 **1 token ≈ 2.75 欧元 ≈ 3 美元 ≈ 21 元人民币** 的折中值计算。

**不存在单一汇率**：上述折算率随所取商品而漂移，这不是换算误差，而是该世界本身的结构——

- 以**底层生存**为锚 → 1 token ≈ 2.5—3 欧元（本表采用此口径，因为叙事最常落在这一层面）；
- 以**企业中层或高管收入**为锚 → 1 token 仅约 0.5—1 欧元，说明同一份 token 在权力结构顶端的购买力被大幅稀释；
- 以**医疗服务**为锚 → 1 token 约 1.5—2 欧元，因为该世界的医疗定价远高于现实同项服务。

换言之，与现实相比，这个世界里**食品相对便宜、住房与数据接入昂贵、医疗贵到摧毁人生**；越靠上层的收入，换算出的 token 面值就越低。任何单一汇率都只能描述某一个阶层的处境。

**2075 年之后的动摇**

2075 年东亚大国开源物质数据化技术后，开源协议联盟据其资料建立了基于「红旗」加密的数据化交通网络（见 `世界观大纲/原稿.md`）。搬运物质的算力不再由信通复合体独占，token 的锚定权首次出现竞争者：联盟可以直接以物质搬运量计价，绕开企业账本。至主线时间点（约 2077 年），**谁有权定义 1 token 值多少克物质**已成为双方冲突的核心议题之一。
